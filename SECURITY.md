# Security reporting

Report security issues privately using GitHub’s vulnerability reporting form. Include the affected version, impact and steps to reproduce with fictional data. Remove credentials, customer data and device identifiers from supporting material. [Report a vulnerability](https://github.com/haydardsx/iquji-community-ops/security/advisories/new)

## 安全报告

请使用 GitHub 私密漏洞报告渠道，注明受影响的版本、影响范围和使用虚构数据的复现步骤。发送材料前，请移除凭据、客户数据及设备标识。[提交私密报告](https://github.com/haydardsx/iquji-community-ops/security/advisories/new)
