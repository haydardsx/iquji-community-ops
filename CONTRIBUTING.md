# Contributing to iQuji Ops

Use GitHub Issues to report a problem. Include the app version, operating system, expected result and steps to reproduce with fictional data. Follow the security reporting instructions for vulnerabilities. [Security](SECURITY.md)

The source-available license requires separate permission to modify or redistribute the app. Obtain that permission from the copyright holder before preparing a code contribution. In your pull request, describe the behavior change and how you tested it, and retain the applicable third-party notices. [License](LICENSE) · [Build instructions](README.md)

## 参与贡献

欢迎在 GitHub Issues 报告问题。请写明软件版本、操作系统、预期结果，以及用虚构数据复现问题的步骤。安全问题请使用私密报告渠道。[安全报告](SECURITY.md)

修改或再分发应用须先取得权利人授权。提交已获授权的改动时，请说明行为变化、验证方法，并保留适用的第三方声明。[源码可见许可](LICENSE) · [构建说明](README.zh-CN.md)
